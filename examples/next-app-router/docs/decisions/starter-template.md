# Starter Template Decisions

The following decisions are locked for the current starter:

- The root route is `/`.
- `landingPageThemes` is the starter preset pack.
- `ThemeProviderWrapper` is the app-level theme provider.
- The active preset owns the page background and surface character.
- Each full-screen section keeps one primary focus.
- Starter docs stay free of business-domain copy.
- The static export target is `dist/`.
- `/start` remains a redirect unless intentionally removed in a product fork.
