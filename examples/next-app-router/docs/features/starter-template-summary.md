# Starter Template Summary

## What This Starter Demonstrates

- preset-driven theming
- dark mode controls
- theme diagnostics
- surface review
- static export flow

## Intended Users

Teams starting a new branded Next.js application on `@atomazing-org/design-system`.

## In Scope

- starter shell
- brand system
- theme controls
- diagnostics routes
- showcase route
- starter docs pack

## Out Of Scope

- business-domain flows
- historical archive execution boards
- product-specific backend integration

## Why This Example Is Canonical

This is the maintained Next.js reference consumer used by the repository smoke checks.
