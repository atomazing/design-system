# Brand System

The starter uses one canonical brand system.

## Ownership

- `src/app/icon.svg`: icon asset used by metadata.
- `src/components/ui/StarterLogo.tsx`: logo mark component.
- `src/components/ui/StarterWordmark.tsx`: wordmark text and lockup.
- `src/app/layout.tsx`: metadata naming and app descriptions.
- `src/components/ui/AppHeader.tsx`: header placement of the brand lockup.

## Consistency Rules

- The icon, header brand, hero brand, and metadata must represent the same sign system.
- If one brand file changes, review the others in the same pass.
- Theme-driven color adaptation is allowed.
- Unrelated alternate marks should not be introduced for individual routes or sections.
