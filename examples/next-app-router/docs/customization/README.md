# Customization Docs

Use this folder to find the exact ownership map for starter-local changes.

- `change-map.md`: file-by-file edit map.
- `brand-system.md`: brand assets, wordmark, and metadata ownership.
- `theme-policy.md`: preset pack selection and visual boundaries.
- `content-map.md`: where route copy and hero copy live.
- `route-map.md`: route purpose and what belongs on each screen.
